# Atividade 7 - Dashboard com Streamlit

Dashboard com os 9 gráficos da Atividade 06, dispostos de três em três, com uma breve análise
abaixo de cada linha e um sidebar recolhível com as informações do aluno.

## Como executar

```bash
pip install -r requirements.txt
streamlit run app.py
```

No sidebar, preencha o número da chamada.
